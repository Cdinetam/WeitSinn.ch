# WeitSinn.ch

One-Page Website für psychologische Beratung von Tam Nguyen (Psychologe lic. phil.).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Setup

```bash
npm install
```

## Entwicklung

```bash
npm run dev
```

Öffnen: [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Deploy

Beliebiges Node-Hosting mit Next.js-Support (z. B. Vercel). Domain später auf WeitSinn.ch zeigen.

## Inhaltshinweise

- Porträtfoto und E-Mail sind als Platzhalter markiert und leicht austauschbar.
- Impressum und Datenschutz sind auf der One-Page als Abschnitte hinterlegt.
